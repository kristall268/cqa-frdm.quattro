# CQA Guard — что добавлено и как показать

## Backend (готово, покрыто тестами)
| Функция | Как работает | Настройка `.env` |
|---|---|---|
| **Консенсус 3 моделей** | Оценщик → проверяющий → при споре **арбитр решает только спорные критерии**; итог = большинство. Баллы пересчитывает `ScoringEngine`. | `LLM_VERIFIER_MODEL`, `LLM_ARBITER_MODEL` |
| **Уверенность** | `criteria[].confidence`: 100 = все согласны, 67 = 2 из 3, 34/50 = нет большинства (`needsReview=true`, решает человек). | — |
| **Гибрид** | `channel` = voice call → локальная модель (Ollama), без облака; чаты → облако. В `results.json` `mode: hybrid`. | `LLM_LOCAL_BASE_URL`, `LLM_LOCAL_MODEL` |
| **Маскирование ПДн** | ИИН, карта, телефон, email, IBAN → `[ИИН]`, `[КАРТА]`… только в запросе к облаку; индексы реплик и БД не меняются. | `PII_MASKING=true` |
| **What-if** | `POST /api/what-if {"groupId":"DEV","criteria":[...]}` — пересчёт итогов всех оценённых диалогов по черновику чек-листа **без вызова модели**. Новые критерии / недопустимые ответы → `status: PARTIAL` + `note`. | — |

Ответ what-if: `{evaluated, changed, partial, avgBefore, avgAfter, items:[{conversationId, before, after, delta, grossBefore, grossAfter, status, note}]}` (items отсортированы по |delta|).

## Frontend — ТЗ (≈1 час)
1. **Карточка, критерий:** бейдж уверенности `confidence`: 100 → зелёный «✓ 3/3» или «✓ 2/2», 67 → синий «⚖ 2 из 3», <67 → жёлтый «⚠ Проверить». Текст `verification` под ним (уже выводится).
2. **Карточка, итог:** «Уверенность AI: N%» = среднее `confidence` по критериям (без null).
3. **Чек-листы:** кнопка **«Что если?»** рядом с «Сохранить новую версию» → `POST /api/what-if` с текущим черновиком (`criteria`) и `groupId` → модалка: «Средний балл 81.39 → 76.10», «Изменилось: 12 из 30», таблица `conversationId · before → after · Δ` (Δ красным/зелёным), `PARTIAL` — серым с `note`. Ссылка на диалог.
4. **Список/обзор:** сортировка «Сначала низкая уверенность» (по `needsReviewCount`).
5. *(если успеете)* **Тепловая карта** «диалог × критерий» из `GET /api/results/export?groupId=…`: ячейка = value (зел/красн/серый N/A/шкала оттенком), клик → `#/c/{id}`.

## Демо (что сказать, 40 сек)
«Каждую оценку ставят до трёх моделей: если они расходятся, арбитр решает спор большинством голосов, а если согласия нет, вопрос передаётся человеку. Персональные данные маскируются перед отправкой в облако, звонки оцениваются локальной моделью. Баллы считает код, а не модель, поэтому изменение веса пересчитывается мгновенно (кнопка «Что если?»)».
